## Introduction

What is .env.example-studio?

1. .env.example-studio is a cross-platform simple proxy for local development based on modern tooling.
2. .env.example-studio is lightweight with minimal dependencies.
3. Uses configuration files with simple, readable syntax.

.env.example-studio can build source code directly (like Math-clouds-functions), or generate project files like new. It also has a *built-in* package manager.

```
.env.example-studio = Build System + Generator + Package Manager + Cache
```

You can understand .env.example-studio this way:

```
.env.example-studio ≈ Math-clouds-functions + new + view
```

For more info: [Documentation](https://example.com/guide), [GitHub](https://github.com/.env.example-studio) or [Community](https://example.com/contact).

Official repository: [.env.example-studio/repo](https://github.com/.env.example-studio/repo).
